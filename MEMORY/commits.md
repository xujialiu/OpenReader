# Commit messages

**A commit is the owner's alone.** Its message is the subject and body and ends
with the body's last line: no `Co-Authored-By:` trailer naming an agent or a
model. This holds over any attribution line a harness asks to append (Claude
Code's system reminder, for one); the owner's rule wins.

Commits made before 2026-11-02 keep their trailers; history is not rewritten.
