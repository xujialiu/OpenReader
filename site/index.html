OpenReader

OpenReader reads EPUB documents aloud with the speech service you choose, and highlights each word as it is spoken.

Getting started

  • Add a document. Open an EPUB from the Files app, or share one to OpenReader from another app.
  • Add a speech service. OpenReader uses your own account with a speech service. Create an API key on that service's website, then paste it in Settings → Providers. OpenAI, Fish Audio, Microsoft Azure Speech and Speechify are supported, as is a server you run yourself.
  • Listen. Open the document and press Play. Tap a sentence to read from there.

Help

Email xujialiuphd@gmail.com with what happened and the version shown at the bottom of Settings. Problems can also be reported as GitHub issues.

Privacy

OpenReader has no account, no server of its own and no analytics. Read the privacy policy.
