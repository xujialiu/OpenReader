## Native capture/restore replaces the misleading iOS scroll-event coordinates (2026-10-28 17:29)

The installed React Native Fabric source reports `scrollView.contentInset`
from `_scrollViewMetrics` (explicit top zero here), not the actual adjusted top
116. Its `scrollTo` command computes the minimum y from that explicit inset
and clamps negative requests to zero unless overflow is enabled. This explains
both the hook's incorrect coordinate conversion and why simply sending -116
through that command would not be sufficient.

The confirmed boundary adjustment is implemented for beta6: two semantic
commands on the existing search control, capture (`browse` or `results`) and
restore (`browse`, `results` or `top`). The native control keeps two transient
logical positions and a weak owning screen; it reads `adjustedContentInset`
and moves the actual associated `UIScrollView` directly. Capture precedes
focus/result navigation, and restoration is retried after content-size changes.
The iOS hook deliberately ignores RN scroll-event coordinates and never calls
its list's `scrollToOffset`; Android retains that existing fallback instead.

The four search host files pass 25 tests. They include the real patched
SearchBar ref forwarding to generated command mocks, capture-before-focus and
capture-before-navigation, native restore after cancellation/clear/Reader
return, the misleading explicit-zero-inset event, and non-iOS fallback
isolation. These assert command wiring and lifetime, not native geometry.

`generate-codegen-artifacts.js -p . -t all -o /tmp/openreader-search-codegen-beta6
--forceOutputPath` exits 0. Its iOS protocol/dispatcher contains both NSString
slot selectors, and its Android interface contains both String slot methods;
Android supplies the iOS-only no-ops that the non-iOS hook never calls. Log:
`/tmp/openreader-search-codegen-beta6.log`. This is successful schema/code
generation, not a native build or device pass. The next tester must regenerate
codegen in its native project and rebuild before exercising these commands.
