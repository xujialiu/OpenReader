# App screenshots and README recordings

Capture the running OpenReader interface on the assigned simulator. The handoff names the screen or sequence, device, installed app/source receipt, appearance and output destination. Read [device testing](../MEMORY/device-testing.md) and [the simulator guard](../test/manual-test/kit/ios-verification.md). Reuse an explicitly handed-off simulator and its data. If it needs a build or installation, return the device and missing prerequisite to the parent for the installer.

1. Check that the installed app and, for Debug, its Metro target match the handoff. Run the capture phase under the shared guard, addressing the device by UDID. Stage recordings, trial images and receipts under the worktree's ignored `.tmp/`.
2. Set up the intended scene in the real app and inspect the rendered screen. For public assets use public-domain text and keep private library entries, credentials, notifications and development overlays off screen. Set and verify guest volume zero before Play. Pause as soon as the required motion is recorded.
3. Follow the requested output:
   - **Named screen or README still.** Capture the specified screen with `xcrun simctl io "$UDID" screenshot "$OUT/screen.png"`. Inspect it at the intended display size. Keep one-off images at the requested destination or return the staged file. Put README deliverables in `assets/readme/`.
   - **README reading GIF.** Record the real screen with `simctl io recordVideo`. For the existing front page, open Chapter I of *Pride and Prejudice* in the dark reader. Use the [silent Kokoro fixture](../test/manual-test/player-and-reading-held/fake-kokoro.cjs) with word timings. Select an uninterrupted passage showing both the word highlight advancing and Following moving the page. Trim setup and idle frames, then encode a looping 640-pixel-wide GIF at 15 fps for the README's 320-pixel display. Check the first, middle and last frames, the actual movement, dimensions, duration and byte size against the previous GIF.
   - **App Store set.** Follow the [device-specific capture guide](../assets/app-store-screenshots/README.md) for scenes, dimensions and Duo displays. Inspect every exported image and check its pixel dimensions and RGB mode. Stage the set for review before replacing tracked files.
4. Return the deliverable paths, source and device identity, measurements, visual checks and any missing scenes. Account for temporary processes, and leave a borrowed simulator available with playback paused. The parent presents the README preview for review before committing the GIF.
